# Yara Max5 — Your AI Companion

Bilingual (Malayalam + English) AI companion app for Android — real-time voice, emotional intelligence, unlimited local memory, multi-API smart brain.

## What's inside

- Real Malayali girlfriend personality — Malayalam+English code-switching, short warm replies, real emotions
- "Hey yara" / "bye yara" wake-word with background listening
- Multi-API brain — Gemini, Grok, OpenRouter, Hugging Face with adaptive auto-switching + manual primary
- Offline local brain — replies keep flowing when all APIs are exhausted
- Unlimited memories, emotion engine + voice modulation
- Floating overlay + quick-reply notifications
- Video call + screen share + Accessibility app-control
- 120+ feature toggles, personality sliders 1-10, analytics dashboard
- About: Hashim — @hashim_m4x

## Build the APK

**GitHub Actions:** push → Actions → Build Yara APK → Run → download `app-debug.apk` from artifacts.

**Local:** `./gradlew :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
